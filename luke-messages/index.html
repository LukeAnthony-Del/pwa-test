Luke Messages keeps what you import on this device. Nothing is uploaded.

Google Messages can’t hand its inbox to a website. Export a backup from the phone that has your texts, then choose the file here.

  1. On that Android phone, install SMS Backup & Restore.
  2. Back up messages. Back up call logs too if you want them here.
  3. Move the XML file to this phone.
  4. Choose the file below. You can choose more than one.

Contacts are a separate file. Export a Google CSV or vCard from contacts.google.com, or a vCard from the Contacts app.
